# 制作与转换

## 从已确认视频方案拆分

1. 固定分辨率、帧率、SRT、口播时间线和素材版本。先检查工程是否被用户手动修改，当前成片和工程优先于旧交付稿。
2. 列出画面独立单元和出现区间。文字从绘制层分离，图片保留原文件，人物保留原始视频，原声单列。已在成片烧录的元素无法靠转换恢复，应从制作源码重导出。
3. Three.js 或 Canvas 的复杂效果按单元开关导出：只显示当前单元，透明背景，同一摄像机、尺寸、帧率与时间轴。导出区间以帧编号记录，首尾采用半开区间 `[first, last)`；人物、文字、背景不得夹带进透明单元。
4. 标题、数字、标签和正文字幕写原生文字。画布运动曲线可转换为位置、缩放、旋转关键帧；化简曲线后检查误差和节奏，不统一改成同一种入场动画。
5. 时间不重叠可复用轨道；同时出现的素材保持原有前后关系。复杂三维单元内部不可编辑，应保留源文件供替换渲染。
6. 对已确认的视频生成清单，再调用构建、检查、安装；普通转换全程通过文件完成，不重新剪辑或主动重做预览。用户要求先审预览时，等待前序视频制作流程完成并获确认后再转换。交付后提示用户重启剪映检查新草稿；剪映内预览、短导出及窗口采集仅按入口文件的按需软件检查规则执行。

## Alpha 与边缘

静态透明元素优先 PNG；透明动态单元可试 ProRes 4444 MOV。普通 H.264 MP4 不作为本方案的 Alpha 容器。保留色彩空间，不对所有素材无条件预乘。

先在白底、深色底检查源文件。进入按需软件检查时，再比较剪映预览与实际导出；不为普通转换自动打开剪映。straight Alpha 合成为 `RGB*a + bg*(1-a)`；premultiplied 为 `RGB + bg*(1-a)`，解释错配可产生亮边或暗边。

对确认**尚未预乘**的 RGBA 帧，曾使用以下兼容候选：

```text
-vf format=gbrap16le,premultiply=inplace=1,scale=in_range=pc:out_range=tv:out_color_matrix=bt709
-c:v prores_ks -profile:v 4 -pix_fmt yuva444p10le -alpha_bits 16
-color_primaries bt709 -color_trc bt709 -colorspace bt709 -movflags +faststart
```

先做短片段核对，再批量。人物缩窗不要简单缩小整张已烘焙竖屏，应从原片裁取头肩或上半身；透明边缘问题不能直接推出“格式无法分割”或“无法美颜”。

## 学习用户精修后的差异

对照最初成片、上一交付工程、用户当前工程和最终成片。时长或剪辑有变化时按内容对齐，不能只对相同秒数截图。

从工程读取真实的文字、字号、字形、缩放、位置、阴影、分段与素材层级；从视频逐帧检查实际呈现。全帧缩略图用于覆盖检查，关键时刻用原分辨率核对，不把抽样误称逐帧观看。

记录可复用偏好：常规字与强调字的比例、字幕安全区、重点词配色、断句节奏、人物窗口和实拍素材使用方式。把构图相关的例外也记下来，避免一个数字约束所有版面。复合片段可能是用户绕过编辑问题的手段，不能倒果为因。

## 保存位置与迁移

1. 用户已确认默认放在剪映下面，不再询问保存位置。读取该电脑剪映实际使用的草稿根目录，创建新工程并在其内收集素材；用户另行指定位置时才按新要求处理。不把 Codex 临时工作区、下载目录或原素材所在的移动设备作为最终引用位置。
2. 在工程内的 `素材` 或 `materials` 文件夹集中收集视频、图片、音频、SRT、可本地备份的字体及必要渲染单元，制作源码另附子目录。只复制，不移动或删除原素材；不要为了完成归档改变已经确认的成片。
3. 遍历主时间线、全部复合片段、富文本内嵌字体和算法处理结果，生成实际依赖清单，记录包内路径、大小和校验值。相同文件可以去重；同名不同内容不能覆盖。官方特效缓存可能是目录，检查存在性不能一律使用 `is_file()`。本地字体、官方效果资源及需在新电脑重新下载的依赖分别说明，不能声称仅复制视频就已打包全部效果。
4. 工作草稿的媒体引用指向自身已收集的素材。现有 `draft_tool.py` 使用绝对路径，不能据此承诺宿主改名、恢复和云迁移后仍自动有效；这些操作分别验证并检查引用是否正确更新。当前已修好的复杂工程不自动迁移，用户测试期间不改工程、素材或索引；另做迁移时须在新副本上保留时间线和效果。
5. 交付前确认没有缺失引用和意外依赖临时目录。用户要求改名或迁移验证，或报告相关故障时，才在隔离副本执行关闭重开、剪映内改名及对应软件检查。跨电脑移动整个项目包后，按新根目录迁移路径并核对依赖；未实际核对软件中的字体、特效、复合片段和短导出时，明确软件兼容未验证。“集中到一个文件夹”本身不代表绝对路径可自动迁移。
6. 仅在用户要求云端上传或迁移验证时，使用剪映自身的草稿上传功能；普通转换不自动上传或下载。需要验证云迁移时，等待上传完成，再下载成独立副本检查画面、字体、效果和短导出。未实际完成上传下载验证时，明确未验证云迁移；保留本地完整项目包。不能把上传成功或本机预览成功当成跨电脑兼容通过，也不能擅自把用户媒体上传到 GitHub。

对故障工程的恢复只在副本中进行。先备份当前版本及索引；绝对路径、素材占位符和嵌套草稿路径分别处理，不能把同一个占位符全局替换为某一个素材。首页未显示新工程时检查草稿索引；需要修改索引则先正常退出剪映，备份并保留其他条目，避免应用用内存状态覆盖文件。生成和文件校验无需退出剪映；用户继续剪辑时暂缓首页登记，不停止其余已授权工作。

## 交付边界

打包素材与字体不授予其再分发许可，也不能替代路径迁移及新电脑验证。新建副本保留原稿；核对全部素材路径，包括原生文字 `content` 内嵌 JSON 的字体路径。复制可变 JSON，不对其做硬链接。真实人物、用户成片和工程仅保留在用户授权的本地目录；云端上传需用户明确授权。
